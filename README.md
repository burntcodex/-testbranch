# Re:Fisch

A fishing macro for Fisch (Roblox), written in AutoHotkey v1.

## Install

1. Install [AutoHotkey **v1.1**](https://www.autohotkey.com/download/) (64-bit). Version 2 won't run it.
2. Download **`Re-Fisch.ahk`** from this page (Code → Download ZIP, or open the file → Download raw file).
3. Put it in its own folder and double-click it. Settings are kept in a `Re-Fisch` folder next to it.

## Updates

Re:Fisch checks this page a few seconds after it starts and asks before installing a newer version.
Your settings and profiles are kept, and the previous version is saved in `Re-Fisch\backup`.

About tab → **Updates**:
- **Check for updates when Re:Fisch starts**: on by default.
- **Channel**: **Stable** (tested builds) or **Test** (every new build first; it may have bugs).
- **Check now**: looks right away.
